# 项目规范目录

本目录存放已确认生效、需持续维护的项目正式规范，包括 docs 目录读写授权、技术约束与工作项规范。按当前任务读取适用文档，不要求每次任务全量加载规范或额外读取本索引。

| 文档 | 适用场景 |
| --- | --- |
| [docs目录读写授权规范](./docs目录读写授权规范.md) | 在访问或操作 `docs/` 前，以及功能任务提交完成交付结果、收到明确取消决定或负责人确认功能阶段结束时完整读取；结束节点执行第 6 章文档收敛检查，同一会话已读且未变化时无须重复读取 |
| [技术规范](./技术规范.md) | 即将编写或修改代码、测试、依赖或工程配置时读取；纯讨论、调研、方案及文档编辑不自动读取 |
| [WI工作项维护规范](./WI工作项维护规范.md) | 覆盖 WI 创建、委托、执行、恢复、维护及验收 |
| [WI工作项文档模板](./WI工作项文档模板.md) | 规范配套模板，供创建、结构补齐、格式检查或迁移 WI 时参考；日常执行与维护按需引用 |

- `docs/specs/`：项目正式规范及配套模板的长期维护位置，不存放具体 WI、任务状态或过程记录。
- `docs/features/`：具体功能的需求、设计方案与验收目标。
- `docs/prototypes/`：原型及其说明。

规范较短时保留单文件；内容增长后再按主题拆分，并为每份规范明确适用任务。功能目录中的 `spec.md` 仍属于该功能的需求规格，无需迁入本目录。
